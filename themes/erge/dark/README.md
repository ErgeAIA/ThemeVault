## 迁移备注

- `accent-foreground` = `#171614`（近黑）：主色 `#F2570F` 偏亮，白字对比度仅 3.42 不达标，故主色块/按钮文字用近黑（WCAG 黑 on accent = 6.15，达标）。
- `text-dim` = `#858079` 经 OKLCH 推导加深，on bg `#1A1714` 对比度 4.56，过 AA。
- 深版为浅版近邻：主色 `#F2570F` 由浅版 `#FF6A2B` 调沉（OKLCH L↓C↑H↓ 更沉更红），深底暖中性。
- 功能色 / 语法色沿用 opensquilla 语义色（橙红家族配套），属 DEC-017 显式豁免。
