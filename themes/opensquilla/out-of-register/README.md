# opensquilla-out-of-register 主题说明

## 元信息
- **来源项目**：opensquilla（Apache-2.0）
- **原始 ID**：`out-of-register`
- **显示名**：Out-of-Register
- **协议**：Apache-2.0
- **色彩方案**：both（继承当前 ground）
- **主题类型**：**expressive skin**（Axis B，路由级 `data-skin` 叠加层，非全局 value theme）
- **提取方式**：基于真实源码 `opensquilla-webui/src/themes/out-of-register/`

## 说明
- 这是**路由级皮肤**，无独立 `tokens.css`，继承当前 value theme 的 ground 令牌，仅叠加结构/纹理/字体层（skin.css）。
- **迁移含义**：目标项目若只有全局主题概念、无路由级 skin 概念，可忽略此套；若保留，当叠加层处理而非独立色板。
- 无 `palette.md`（无独立色板）。
