## 预览页改造方案：脚本生成 SVG → 数据驱动 SPA + 瀑布流

### 目标
解决 4 个渲染问题（色块重叠/两端对齐错乱/标签错乱/固定尺寸压缩），并把「每次脚本重生成」范式换成「数据驱动运行时渲染」——主题增多无需改前端、无需重生成预览。

### ① 数据层：扩展 gen_index.py（核心）
- **theme 加 `tokens` 字段**：仅 value-theme，格式 `{role: value}`（dict，值取自 palette.md 原文，复用现有 parse_palette 的 value）。skin 无 tokens（null）。kind/section 不入数据（由前端内嵌映射决定），减小体积。
- **额外输出 `preview/data.js`**：内容 = `window.__TV = {<完整 INDEX.json，含 tokens>};`。file:// 双击可用（`<script src>` 无 CORS 限制，比 fetch 稳）。
- 落盘逻辑：`gen_index.py --write` 同时写 `INDEX.json` + `preview/data.js`（同一份数据两种封装）。

### ② 修数据坑（必须）
- **5 个 theme 的 `scheme='{scheme}'` 占位符**（everforest/dark+light、rose-pine/dawn+main+moon）：其主题 README 元信息「色彩方案」行写成了字面 `{scheme}`（生成脚本未插值）。直接修这 5 个 README 的该行为 `dark`/`light`/`light`/`dark`/`dark`，重跑 `gen_index.py --write` 即归位。
- 其余数据（#007 skin brand/palettePath=null）已在现有逻辑正确跳过，SPA 沿用跳过。

### ③ SPA 层：新 `preview.html`（静态手写，原生 JS，无框架/构建）
**结构**：`<header>`（标题 + 搜索框 + scheme chips）+ `<main id="grid">`（瀑布流容器）+ `<script src="data.js">` + 内联渲染 JS。

**布局（解决 4 问题）**：
- **瀑布流**：`#grid { columns: 4 320px; column-gap: 18px; }` + `.card { break-inside: avoid; margin-bottom: 18px; }` → 卡片高度自适应内容，Token 多自然变高，错落排列。
- **色块网格**：`.swatches { display: grid; grid-template-columns: repeat(auto-fill, minmax(78px, 1fr)); gap: 6px; }` → auto-fill 使每行填满，**不满行也均匀**（彻底解决"两端对齐错乱"）；色块 + label 在固定列宽内，长 label 用 `overflow:hidden; text-overflow:ellipsis` 防溢出重叠。
- **底部 tags**：`.tags { display: flex; flex-wrap: wrap; gap: 5px; }` → 自然换行，**不硬编码列数**，长短 tag 自适应。
- **卡片自身配色**：每卡用主题 `bg`/`text` 作 CSS 变量 `--card-bg/--card-fg`，卡片背景=主题 bg、文字=主题 text（与现 SVG 一致）。

**渲染逻辑（JS）**：
- 读 `window.__TV`，遍历 families/themes，跳过 `type != 'value-theme'` 或无 tokens 的（即 #007 skin）。
- 每卡：标题行 + 右上 meta（scheme·tokens·license）→ AA 徽标行（text/text-muted/text-dim on bg，家族感知）→ 品牌色 swatch（brand.color + 深字/浅字）→ 分区色块（内嵌 SECTION_ROLES / FAMILY_SECTION_ROLES，ergemd 走原生词表）。
- 内嵌复用：SECTION_ROLES、FAMILY_SECTION_ROLES（ergemd）、BADGE_ROLES（opensquilla/catppuccin/ergemd，其余兜底 opensquilla）、BG_TEXT_ROLES（ergemd）。把这 4 个常量从 gen_preview.py 移植成 JS 对象。
- AA 对比度算法：移植 `luminance`(sRGB) + `contrast`(WCAG) 成 JS（前端复算徽标，不依赖预生成）。
- 搜索/筛选：复用现有 `apply()` 逻辑（name/family/number 含 "#007" 去前导#，scheme 字符串相等）+ `setScheme()` chip 切换；过滤用 `display:none`（不重建 DOM）。

### ④ 退役旧范式（gen_preview.py + SVG）
