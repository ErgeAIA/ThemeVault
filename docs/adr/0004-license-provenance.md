# ADR-0004 许可证与 provenance 策略

- 状态：**已接受**（2026-08-04）
- 关联：ADR-0001、ADR-0002

## 背景

ThemeVault 收集的是**第三方开源主题**，可能包含衍生调色板（如 arctic = Nord 衍生）。
协议与署名若丢失，复用时会踩法律/礼貌红线。

## 决策

1. 每套主题与每个家族必须登记协议：主题 README「协议」字段 + 家族 README 首行来源。
2. 衍生调色板必须标注上游：`arctic` 标注「Nord 衍生（MIT，需署名 Sven Greb）」，
   `INDEX.json` 的 `licenseNote` 字段承载该信息。
3. 原始源码一律进 `themes/<family>/_source/`（只读备查），提取必须基于真实源码
   （ADR 外规则：禁止只靠 README 推断颜色值）。
4. 入库门槛：来源项目须有明确开源协议；无协议或协议不明的一律不收录。
5. 迁移方义务：迁移指南（`docs/migration-guide.md`）明确要求保留协议与署名。

## 影响

- 新家族入库时，第一步就是确认并登记来源仓库 + 协议（见 ADR-0001 工作流）。
- 协议分布可随时从 `INDEX.json` 统计（当前 2026-08：Apache-2.0 × 14 + MIT × 44 + AGPL-3.0 × 14，含 1 套 Nord MIT 衍生需署名）。
