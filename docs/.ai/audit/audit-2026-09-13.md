## 3. 问题清单

严重度：中 = 会误导后续工作或破坏已声明不变量；低 = 局部、当前无实际损害。无高严重度问题。

### 中

**F1 · 质量 | INDEX.json 损坏时静默全量重编号，破坏「已有编号永不变」不变量**
- 证据：`scripts/gen_index.py:237-240`（`load_old_numbers` 捕获 `JSONDecodeError/OSError` 后返回 `{}`）+ `scripts/gen_index.py:249-260`（空映射时按遍历顺序分配 1..N）。INDEX.json 一旦损坏/被截断，重跑 `--write` 会把全部 74 个编号静默重排，INDEX.md 编号列与用户引用习惯（#N）全部漂移，且无任何报错。
- 方向：INDEX.json 存在但解析失败时硬失败（exit 1 提示修复），而不是当首次运行处理；可另留 `.bak` 兜底。不改栈。

**F2 · 质量 | 预览页对 8 位 hex 用伪造亮度算对比度，与 Python 端口径不一致**
- 证据：JS `luminance` 对非 6 位 hex 返回 0.5（`preview.html:167`），随后 `contrast()` 照常算出看似合理的比率并标 ✓/✗（`preview.html:195-196`）；Python 端同场景返回 None，textContrast 键落为 null（`scripts/gen_index.py:133-136`、`scripts/gen_index.py:200-201`）。
- 实测影响面：8 位 hex 出现在 30 个 palette.md；其中 `--text-muted/--text-dim` 为 8 位 hex 的有 5 套（ayu/dark、ayu/mirage、ayu/light、jellyfish/dark、synthwave/dark，grep 实测），这 5 套的预览 AA 徽标显示的是无意义的「假比率」，而 INDEX.json 的 `textContrast.textMutedOnBg` 为 null——预览与机器守卫口径互相矛盾。取色防呆依赖这对口径一致（AGENTS.md 硬性规则 8）。
- 方向：JS 与 Python 统一为「非 6 位纯色 → 不显示数字（—）」；或两端都支持 8 位 hex（剥离 alpha 后计算并标注）。不改栈。

**F3 · 架构 | L1 角色集/分区在 4+ 处手抄重复，漂移风险已现实存在**
- 证据：`scripts/gen_vscode.py:104-170`（SECTIONS + COMMON_MAP）、`scripts/gen_catppuccin.py:40-99`（MAPPING + CONTRACT）、`preview.html:127-157`（SECTION_ROLES / FAMILY_SECTION_ROLES / BADGE_ROLES / ERGE_MD_L1_MAP）、`docs/migration-guide.md` §2.2-2.5 矩阵。gen_index.py 以 contract.json 为唯一事实源（好），但预览与生成器各自硬编码同一套角色分组；ergemd→L1 映射另有三份（`preview.html:150-157`、`scripts/gen_ergemd.py:207-217`、migration-guide §2.5）。当前内容一致（实测比对过分组），但每加一个家族/角色都要多处手改。
- 方向：由 `gen_index.py` 从 contract + 家族配置派生「分区/角色分组/家族映射」写入 data.js（预览只读数据）；或最小化——加一个校验步骤核对各处清单一致。不改栈。

**F4 · 技术栈 | PyYAML 依赖未声明，环境不可复现**
- 证据：`scripts/gen_vscode.py:23` `import yaml`（falcon/omni 两家族的 YAML 锚点源必需）；仓库无 requirements.txt / pyproject.toml / lock（根目录 `ls -a` 实测）；AGENTS.md Toolchain 未记录。新机器上 `gen_vscode.py` 直接 ImportError。
- 方向：补最小 `requirements.txt`（或 pyproject + uv 锁定），Toolchain 表同步一行。不改栈。

### 低

**F5 · 质量 | 生成物非字节幂等：generatedAt 时间戳**
- 证据：`scripts/gen_index.py:365`（`datetime.now` 写入 generatedAt）与 `:380-385`（data.js 复制同一 index）；两个文件均被 git 跟踪。任何一次 `--write`（哪怕零数据变化）都会产生时间戳 diff 噪音，与 AGENTS.md「生成器必须幂等可重复」（`AGENTS.md:167`）存在张力（数据幂等、字节不幂等）。
- 方向：省略 generatedAt，或内容 hash 无变化时跳过落盘/保持原时间戳。

**F6 · 质量 | 8 位 hex 使 shades 两套主题品牌色为 null（已文档化的已知事实）**
- 证据：`themes/shades/dark/palette.md`、`themes/shades/super-dark/palette.md` 的 `--accent` 为 `#FAD000dd`（grep 实测）；`brand_of` 只接受 `#` 开头且 luminance 可算的值（`scripts/gen_index.py:160-173`）→ brand=null。已在 `docs/brand-colors.md:68` 标注为源事实。本审计不重复报缺陷，仅指出：brand 链路对 alpha hex 无降级策略（如取 6 位主色并标注）是可选项，需用户决策（涉及「改值」边界，硬性规则 7 同类）。

**F7 · 质量/架构 | vue 家族 5 个 fallback 约定 hex 不在源码中，与「色值原文」规则的张力**
- 证据：`scripts/gen_vscode.py:239-246`（vue fallback：text-muted `#586e75`、warn `#e6a23c`、danger `#dc322f`、info `#268bd2`、queued `#b58900`）；grep 实测这 5 个值均不存在于 `themes/vue/_source/vue-theme.json`、`vue-hc.json`（对照组：jellyfish 的 `#00f7ff`/`#FF92A5` 与 vue 的 `#19f9d8` 均见于各自源文件）。AGENTS.md 硬性规则 3（`AGENTS.md:51`）要求色值源码原文；家族 README 与 palette 备注以「约定」标注了这一偏离（`scripts/gen_vscode.py:456-457`），OnePage 入库时同类问题则按「不发明 hex」处理（`docs/.ai/decision-log.md` DEC-001）。两个家族执行口径不一致。
- 方向：补一条 DEC 明确「缺失角色允许约定值」的边界与标注规范；或把 vue 缺口改回「留空/继承」口径。

**F8 · 质量 | 手写 jsonc 解析器两处潜在缺陷（当前输入未触发）**

## 5. 方向摘要

按优先级（均为方向，不是待办与排期；全部不换栈）：

1. **守卫口径统一**（F2）：预览与 gen_index 对非 6 位 hex 统一输出「无数据」，消除假对比度——这是取色防呆链路的口径问题，优先级最高。
2. **编号不变量加固**（F1）：INDEX.json 解析失败改为硬失败。
3. **可复现性**（F4/F5）：声明 PyYAML 与 Python ≥3.10 下限；处理 generatedAt 的字节幂等。
4. **单一事实源延伸**（F3/F11/F12）：把角色分组、家族映射、family 显示名从预览/生成器硬编码收拢到 gen_index 派生的 data.js。
5. **口径决策留痕**（F6/F7）：8 位 hex 品牌色降级、缺失角色「约定值」边界，各补一条 DEC。
6. **文档小修**（F13-F16）：glossary 编号、README 进度、preview.html 注释、progress「尚无提交」（后者建议 vibe-sync）。
