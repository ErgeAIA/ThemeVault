# Changelog

All notable changes to this project will be documented in this file.

This project has **no release artifacts**. Changes are separated by date, like a diary of one day's work. Category names follow [Keep a Changelog](https://keepachangelog.com/en/1.0.0/); SemVer version numbers are not used.

## [Unreleased]

## 2026-10-10

### Added
- Add the `opencode` family: DSH OpenCode theme collection (@`9839cb3`, MIT aggregation) — 72 theme variants (35 dual-scheme dark/light + 2 single-scheme), generated by `scripts/gen_opencode.py`, with family contract / intent / extract / mapping
- Add light schemes for 4 families (synthwave / tokyonight / nord / dracula) via `scripts/gen_s2b_light.py` (DSH OpenCode→L1 mapping, all 29 required roles filled + contract-fallback notes)
- Theme count 101 → 150, family count 22 → 23

### Changed
- `gen_opencode.py`: add the `AA_EXEMPTIONS` constant to inject AA contrast known-deviation notes (annotation only, no value changes)
- Register the AA contrast warnings of both solarized light themes (`solarized/light` #034, `opencode/solarized-light` #136, textOnBg 4.13) as known deviations — source values kept unchanged (DEC-015)
- one-dark-pro / shades stay dark-only: their DSH sources are a reduced 28-role variant missing text-muted + syntax*, which would require heavy contract fallbacks (DEC-014)
- Remove the "Current progress" section from root `README.md`; `docs/.ai/project-progress.md` is now the single source for progress, and open TODOs were migrated there
- opencode light variants whose values are identical to dark (catppuccin-frappe / catppuccin-macchiato / nightowl, 3 themes) are now archived as dark, so the Light filter no longer shows dark-looking themes; **no color values were changed**, only the archival label (noted in palette and README)

### Fixed
- Card background: the opencode family uses native `background`, not the L1 `bg`, so every card fell back to a placeholder dark tone (35 light themes rendered dark). Added `BG_TEXT_ROLES` / `BADGE_ROLES` entries
- Compare matrix: added an opencode -> L1 role mapping; the opencode family previously rendered as an entirely empty column
- Readability: AA badges and number / brand / font / scheme tags now pick the higher-contrast variant (dark or light) against the card background (was as low as 1.32 on light theme cards; now worst case 5.98 / 6.47)
- Preview polish: empty state when a filter matches nothing, Esc-to-close and `aria-expanded` on the family dropdown, press feedback on controls, unified radius scale (6 / 8 / 12), code sample no longer references a real theme name
- Cards whose background is `transparent` (lucent-orng / lucent-orng-light) fall back to a scheme-appropriate neutral base; previously the transparent card showed the page's dark background and, combined with dark theme text, was unreadable. The source value is labeled on the card
